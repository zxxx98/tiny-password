# 0001 · V1 边界决策与 T01 探针结论

状态：已接受
日期：2026-09-05
关联：[行动计划](../../docs/superpowers/plans/2026-09-05-tiny-password-action-plan.md) §2 D01–D12；[设计文档](../specs/2026-09-04-tiny-password-design.md)

本文记录行动计划 §2 中 D01–D12 的落地规则。每条区分三类信息：

- **设计要求**：设计文档已确认的内容，不得偏离。
- **决策**：T01 固化的实施规则（可测试、有验证入口）。
- **探针结论**：`scripts/probes/` 实际运行结果（见 §13）。

## D01 初始化令牌日志例外

- 设计要求：敏感值不入日志；初始化令牌必须输出到容器日志。
- 决策：初始化令牌是唯一的显式日志例外。仅在实例尚未初始化时，启动阶段以专用事件 `setup_token_issued` 输出一次；初始化成功后销毁校验材料，之后任何状态下都不得再次输出。日志扫描的允许列表必须精确匹配该单一事件名，不得放行任意 token 字段。验证入口：T05 集成测试、T30 日志扫描。

## D02 Secure Cookie 与局域网 HTTP

- 设计要求：Cookie 带 `Secure`；默认面向内网部署。
- 决策：生产登录必须依赖浏览器可接受的 HTTPS。三种许可形态：Cloudflare Tunnel（默认推荐）、已有 TLS 反向代理（需可信证书）、LAN 直连 HTTP 仅限显式设置 `TP_ALLOW_INSECURE_COOKIES=1` 的开发/评估模式，文档必须标注风险。默认关闭开发放宽。验证入口：T02 配置项、T29 部署验证、T30 安全检查。

## D03 主密钥 Secret 只读

- 设计要求：主密钥以只读 Secret 挂载；恢复时用源密钥解密、目标密钥重加密。
- 决策：恢复流程永不写入 Secret 挂载路径。恢复前副本与候选数据库保留到迁移、完整性检查与提交全部完成后；失败回滚到原库。验证入口：T25 故障注入测试。

## D04 7-Zip 安全口令通道（探针已验证）

- 设计要求：7z 归档口令不得出现在进程参数、日志或错误消息中。
- 探针结论（`scripts/probes/archive-password.sh`，真实容器内 25/25 通过，7-Zip 26.03）：
  - **创建**必须带空 `-p`（即 `-p` 后无值）；不带 `-p` 时 7-Zip 会**静默生成未加密归档**，此行为已固化为探针守护断言。
  - **列表/测试/解压**必须**省略** `-p`；空 `-p` 被解释为空密码，直接失败且不再提示。
  - 口令经 stdin 管道传入：单行 + EOF。进程不回收回显（非 TTY 无回显）；口令不出现在 argv、environ、stdout/stderr。
  - 错误口令：退出码 2，输出 "Cannot open encrypted archive. Wrong password?"，不写出目标文件。
  - 关闭 stdin：立即失败（rc 255），无挂起。
  - Unicode 口令（含 CJK、emoji、空格、符号）创建/解压往返成功。
  - `-mhe=on` 生效：归档字节中搜不到文件名；`-slt` 列表显示 AES。
  - PTY（`script`）方式出现口令回显泄漏，**弃用**；生产适配器只使用管道。
  - `-mem=AES256` 是 zip 格式专属参数，对 7z 格式返回 E_INVALIDARG；7z 格式默认即 AES-256。
- 决策：
  - 生产镜像使用官方 7-Zip 26.03 静态二进制（amd64/arm64 同源），SHA256 见 0002。
  - 备份口令与个人归档口令禁止包含 LF/CR 字节（行协议约束），配置时校验（T21/T20）。
  - 7-Zip 子进程 stdout/stderr 不直接进日志（T19 固化）。

## D05 最后管理员保护

- 设计要求：删除账号等不可逆操作有明确边界；设计未列角色变更。
- 决策：V1 不提供角色变更和管理员重置密码接口。拒绝删除或禁用最后一个可用管理员，检查与写操作同事务完成以避免并发竞态。管理员删除自己禁止。验证入口：T09。

## D06 共享条目的收藏/标签

- 设计要求：共享条目只有创建者可修改。
- 决策：收藏与标签属于条目本身，遵循“创建者唯一写入者”。非创建者（含管理员）只读。V1 不新增个人共享收藏映射表。验证入口：T10/T17。

## D07 预认证 CSRF

- 设计要求：所有写请求要求 CSRF token；初始化/登录发生在会话建立前。
- 决策：发放短期预认证 CSRF 上下文（匿名会话 Cookie + 绑定 token），写请求同时校验 token 与 Origin/Referer。登录或初始化成功后轮换上下文。初始化接口仍必须验证一次性令牌。验证入口：T05/T07。

## D08 个人活动接口

- 设计要求：UI 有个人活动页；API 资源列表未单列。
- 决策：新增 `GET /api/v1/auth/activity`，只返回当前操作者自身的脱敏事件（游标分页）。系统全量审计仅管理员可读（`/api/v1/admin/audit/*`）。验证入口：T08/T15。

## D09 字段与资源上限

- 设计要求：密码和输入必须有防 DoS 上限；锁定调整范围待定。
- 决策（可测试上限，T01 固化）：
  - 登录密码：最少 12 字符，最多 1024 UTF-8 字节，允许全部 Unicode，禁止 NUL。
  - 条目加密负载：明文 JSON 最大 256 KiB。
  - 标签：每条目最多 32 个，每个 1–64 UTF-8 字节，去重。
  - login 网址：1–16 个，每个 ≤ 2048 字节。
  - 用户闲置锁定调整范围：5–30 分钟。
  - 个人归档（transfer）：压缩体 ≤ 64 MiB，展开后 ≤ 128 MiB，文件数 ≤ 512，单文件 ≤ 32 MiB，处理超时 120 s；同用户并发 1，全局并发 2。
  - 整实例归档：展开上限按部署资源显式配置（`TP_BACKUP_MAX_EXPANDED_BYTES`），不设静默默认。
  - 归档/导入请求体上限：上传归档 ≤ 96 MiB（对应 64 MiB 压缩体 + 清单裕量），JSON 请求体 ≤ 1 MiB。
- 调度 DST：跳过时刻在下个有效时刻执行；重复时刻每天只执行一次；停机漏跑恢复后补一次。验证入口：T23。

## D10 个人归档范围

- 设计要求：导出只含成员个人条目和本人创建的共享条目。
- 决策：默认导出未删除条目的当前版本，不携带历史/回收站。导入统一重映射内部引用；未被包含的地址引用需用户补全。UI 明示该范围。验证入口：T20。

## D11 临时敏感文件

- 设计要求：临时敏感文件权限受限，任务结束即清理。
- 决策：含明文导出 JSON 或主密钥的中间文件放入受限 tmpfs（目录 0700、文件 0600）；用大小与并发上限防 OOM；失败不回退普通磁盘。主机 swap 与内存属于运维信任边界，文档说明。验证入口：T19/T20/T21。

## D12 字体自托管

- 设计要求：Newsprint 使用 Playfair Display / Lora / Inter / JetBrains Mono；PWA 动态内容全禁缓存。
- 决策：四套字体在镜像内自托管并附许可证文件，配置系统字体回退；不引入 Google Fonts 网络依赖。Service Worker 仅缓存带内容哈希的静态资源与离线说明页。验证入口：T14/T28。

## 14. 未解决问题

- 7-Zip 26.03 与 Alpine apk 包尚未比对：生产镜像最终使用官方静态二进制，无需 apk；若 T19 改变选型需回滚本决策。
- SQLite 快照归一化（journal_mode=DELETE）在超大库上的耗时待 T21 实测；必要时改为对快照执行 passive checkpoint。
- 官方 7-Zip 发布页未提供权威 SHA256 文件；0002 中校验值由本次下载产物计算，发布前（T30/T31）需对照独立来源复核。
