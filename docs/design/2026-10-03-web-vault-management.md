# Web 保险库管理与密码编辑

## 功能

- 列表支持名称升降序、更新时间升降序、最近创建排序；支持搜索、类型、保险库、标签、收藏组合筛选。
- 按标签、类型、保险库分组；多标签条目会出现在各标签组，选择状态按条目 ID 共用。没有独立文件夹模型。
- `/`、`Ctrl/⌘ K` 聚焦搜索，`N` 新建；输入框和弹窗内不会误触新建快捷键。
- 登录条目可在列表直接复制账号、密码；仅在明确点击时读取详情，密码复制记录审计，剪贴板 30 秒后尽力清理。
- 详情可复制为新条目：打开可编辑的个人草稿，保留类型、字段、标签，保存前不写入。
- 多选支持批量移入回收站、移动、添加标签、复制到个人保险库。全选只选择已加载条目；选择状态绑定用户及查询、筛选、排序对应的结果。搜索防抖和替换结果加载期间，旧行的选择及批量操作均禁用；加载更多保留选择。普通刷新取消选择，批量刷新保留失败项用于重试。
- 密码健康可展开问题清单，按弱密码、重复、过期筛选并打开详情；保存、历史恢复、删除和批量操作后重新计算。
- 登录编辑器内可配置密码长度、字符类别、排除易混淆字符，调用现有安全随机生成接口并填入当前草稿。生成期间禁用保存和离开编辑器。
- 密码强度用本地 zxcvbn 估计，按需加载，不向外部服务发送密码。健康报告的弱密码规则仍为少于 12 个字符，两个指标的规则均在页面明确说明；没有增加外部泄露检测。

## 权限、分页与重试

`POST /api/v1/items/browse` 返回授权范围内的元数据与解密标签，不返回密码等负载。查询放在请求体内。无搜索、无标签过滤的时间排序使用 SQL 排序及游标分页，每页最多解密页大小加一条。需要解密的时间排序筛选按 SQL 顺序扫描，收集足够匹配项后停止。名称排序仍扫描全部授权候选，使用容量为页大小加一的堆保留全局最优候选，避免积累全库匹配元数据。扫描最多同时读取 64 条密文（无解密过滤的时间分页按页大小读取）；每条解密负载处理后释放。标题和标签仍保存在加密负载里，没有新增明文列或索引。游标绑定用户、全部过滤参数和排序方式，相同排序键以 ID 排序，防止重复或遗漏。

`POST /api/v1/items/browse/tags` 独立加载授权范围、类型、收藏筛选下的标签候选，仅保留去重标签并排序返回。Web 在这些筛选改变或写入后重新加载候选，搜索、名称排序和加载更多复用已加载标签。该接口仍需解密全部授权候选，内存随不同标签数量增长；名称排序的解密次数也仍随授权候选数量增长。分页没有跨请求快照，并发更新可能改变后续页成员。

快速复制在详情读取阶段随卸载取消请求；剪贴板写入不可取消，成功后即使组件已卸载也安排 30 秒清理，并提交仅含字段类别的密码复制审计。审计不使用组件取消信号，普通页面切换不会取消；仍遵守 API 客户端在锁定、退出时的全局请求取消。卸载后不更新组件 UI。清理前读取剪贴板，仅当内容仍等于复制值时尝试清除。浏览器权限及读取/写入之间的并发变化仍可能限制清理，审计网络失败仍为尽力处理。

批量操作沿用现有条目权限，每项独立提交，并报告成功数及各项失败原因。其他成员创建的共享条目可以复制到个人保险库，不能批量修改。标签和移动更新校验选中时的版本，冲突要求刷新后重新选择，不覆盖并发修改。

复制和移动发生传输失败时，当前页面保留原请求体与幂等键用于重试；成功项解除选择，失败项保持选中。页面关闭或会话退出会清空这些内存状态。批量操作不是整批事务。

跨保险库移动继续使用现有语义：创建新条目并删除源条目，历史不迁移。移动到共享后全体成员可读；有不符合目标保险库可见性的地址引用时，单项失败并给出提示。这些影响在确认弹窗中说明。

## 验证

- Web 测试覆盖组合筛选、标签分组、批量部分失败、版本冲突、标签合并、幂等重试、共享只读复制、健康跳转、延迟筛选及搜索响应的旧选项禁用、加载更多和后续页失败重试、延迟剪贴板写入期间卸载后的清理及审计、写入失败和保留后续复制内容、快捷键和生成请求清理。
- API 集成测试覆盖全部排序方式、跨页完整性、组合过滤、游标隔离、未授权条目及标签不可见、列表不返回负载、健康结果标题、120 条数据的逐页解密次数、相同排序键及中文长名称。
- 浏览器测试覆盖真实生成与保存、复制草稿、分组/筛选、批量标签/移动/回收站、健康清单与快速复制，并复验原有保险库桌面和移动布局。
